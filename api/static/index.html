배달 예상 시간 API

모델: {{model}}

가게에서 배달지까지의 거리와 밀려 있는 주문 수로 배달 예상 시간(분)을 계산합니다.

바로 해 보기

엔드포인트

메서드경로설명
POST/eta배달 예상 시간(분)을 계산
GET/health서비스 상태와 현재 구현체 이름

요청 본문 (POST /eta, JSON)

필드타입규칙
distance_kmnumber0 이상. 가게에서 배달지까지 거리(km)
pending_ordersinteger0 이상. 지금 밀려 있는 주문 수

요청 예시

curl -X POST /eta \
  -H "Content-Type: application/json" \
  -d '{"distance_km": 3, "pending_orders": 2}'

응답 예시 (200)

{"minutes": 28.94, "model": "{{model}}"}

잘못된 입력 (422)

음수, 숫자가 아닌 값, 정수가 아닌 주문 수, 빠진 필드는 422 를 돌려줍니다. detail[].loc 에 어느 필드가 잘못됐는지 들어 있습니다.

{"detail": [{"type": "greater_than_equal", "loc": ["body", "distance_km"],
             "msg": "Input should be greater than or equal to 0", "input": -1}]}

상태 확인

curl /health
# {"status": "ok", "model": "{{model}}"}
